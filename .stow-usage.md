# Stow Quick Reference

## Common Commands

```bash
# Install all configs
cd ~/dotfiles && stow */

# Install specific package
cd ~/dotfiles && stow rofi

# Uninstall package
cd ~/dotfiles && stow -D rofi

# Reinstall/refresh package
cd ~/dotfiles && stow -R rofi

# Dry-run (simulate without changes)
cd ~/dotfiles && stow -n rofi

# Verbose output
cd ~/dotfiles && stow -v rofi
```

## Adding New Configs

1. Create package directory structure:
   ```bash
   mkdir -p ~/dotfiles/package-name/.config/package-name
   ```

2. Copy your config:
   ```bash
   cp -r ~/.config/package-name/* ~/dotfiles/package-name/.config/package-name/
   ```

3. Remove original and stow:
   ```bash
   rm -rf ~/.config/package-name
   cd ~/dotfiles && stow package-name
   ```

## How It Works

Stow creates symlinks from `~/.config/` to `~/dotfiles/package/.config/`:

```
~/.config/rofi -> ~/dotfiles/rofi/.config/rofi
```

This means:
- Edit files in `~/dotfiles/` (version controlled)
- Changes apply immediately (symlinked)
- Easy to backup with git
